# Store data-use answers

- **Data collected:** None. Settings, a cache of original titles and restore counters stay in the browser's extension storage.
- **Data sold or transferred:** None. There is no server, analytics, telemetry or remote configuration.
- **Network:** Requests go only to YouTube (`www.youtube.com` oEmbed and player endpoints, `i.ytimg.com` thumbnails).
- **Purpose:** Show creator-uploaded titles, descriptions, thumbnails and audio instead of automatic translations and dubs.
- **User control:** Each feature can be switched off; cached titles and counters can be cleared on the settings page; uninstalling removes everything.
